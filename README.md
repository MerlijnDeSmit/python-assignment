# python-assignment

Repository contains the following files:

- `Bignumbers_documentation.pdf` Please read this first!
- `bignumbers.py` The main Python script, designed to output the lowest prime factors (>1) of numbers in a list of numbers, and to determine whether the number in the list is prime if the lowest prime factor is equal to the number itself.
- `allprimenumbers.txt` A list of large prime numbers, in order to test the script.
- `largenumbers.txt` A list of prime and non-prime large numbers, in order to test the script.
- `largenumbers_error.txt` A list of large numbers with input errors, in order to test the script's error handling functionality.
- `smallnumbers.txt`A list of small numbers with obvious lowest prime factors, in order to test the script.

For further guidance, please consult the file `Bignumbers_documentation.pdf`.
